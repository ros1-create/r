# 🐾 Telegram-бот «Эксперт по породам кошек»

Telegram-бот на базе **aiogram 3** и нейросети **Google Gemini**, рассказывающий всё о различных породах кошек в спокойном и умиротворяющем стиле.

---

## 🌟 Возможности бота

- **Поиск и описание пород**: Внешний вид, характер, особенности ухода, здоровье и история породы.
- **Подбор кошки**: Рекомендации питомцев под образ жизни (для семей с детьми, гипоаллергенные, спокойные или активные).
- **Спокойный тон общения**: Умиротворяющие, понятные и структурированные ответы.
- **Индикация набора текста**: Во время генерации ответа в чате отображается статус «печатает...».
- **Отказоустойчивость**: Автоматический повтор запроса с переключением на запасную модель `gemini-3.5-flash` при ошибке 503 (перегрузка сервиса).
- **Безопасность**: Токены и ключи хранятся в `.env` и никогда не попадают в git-репозиторий.

Откройте файл [`.env`](file:///C:/Users/a/.gemini/antigravity/scratch/cat_breed_bot/.env) и укажите ваши ключи:

```env
# API-ключ Gemini, полученный в Google AI Studio (https://aistudio.google.com/)
GEMINI_KEY=AIzaSy...
```

### 2. Запуск бота

Для запуска используйте команду:

```bash
python bot.py
```

или с явным указанием пути к интерпретатору:

```powershell
& "C:\Users\a\AppData\Local\Programs\Python\Python311\python.exe" bot.py
```
